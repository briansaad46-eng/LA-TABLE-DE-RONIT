# LA TABLE DE RONIT – אתר + Supabase

## מה בחבילה
| קובץ | תפקיד |
|---|---|
| `index.html` | אתר הלקוחות. טוען תפריט מ-Supabase ושומר כל הזמנה לפני פתיחת הוואטסאפ |
| `admin.html` | לוח ניהול לרונית: הזמנות (עם סטטוס) וניהול תפריט (הוספה, עריכה, הסתרה, מחיר, העלאת תמונה) |
| `config.js` | כל ההגדרות: מפתחות Supabase, מספר וואטסאפ |
| `schema.sql` | טבלאות, הרשאות ואחסון תמונות, כולל 20 המנות הקיימות |
| `hero.jpg`, `s1.jpg`...`p6.jpg` | תמונות הפתיחה והמנות, באותה תיקייה עם `index.html` (ללא תת-תיקיות) |

## הקמה (כ-10 דקות)
1. נכנסים ל-supabase.com, יוצרים פרויקט חדש.
2. **SQL Editor** > New query > מדביקים את `schema.sql` > Run.
3. **Authentication > Users > Add user**: יוצרים משתמש לרונית (אימייל וסיסמה, לסמן Auto Confirm).
4. **Authentication > Sign In / Providers**: מכבים את **Allow new users to sign up**. זה חשוב: כל משתמש מחובר נחשב מנהל.
5. **Project Settings > API**: מעתיקים את `Project URL` ואת `anon public` key אל `config.js`. לעולם לא להשתמש ב-`service_role`.
6. מעלים את כל התיקייה לאחסון סטטי (Netlify Drop, Vercel, Cloudflare Pages או GitHub Pages).
   לבדיקה מקומית: `python3 -m http.server` בתוך התיקייה ופתיחת `http://localhost:8000`.
7. לוח הניהול: `כתובת-האתר/admin.html`.

## איך זה עובד
- **לקוח לוחץ "שלח הזמנה":** ההזמנה נשמרת בטבלת `orders`, ובמקביל נפתחת הודעת וואטסאפ מוכנה. אם השמירה נכשלה, הוואטסאפ עדיין נפתח.
- **מי רואה מה:** גולשים רק קוראים תפריט ויוצרים הזמנה. רק משתמש מחובר רואה הזמנות או משנה תפריט (מוגדר ב-RLS).
- **תמונות חדשות:** מעלים בלוח הניהול, הן נשמרות ב-Storage ומוקטנות אוטומטית.

## הערות
- המחיר בהזמנה נשלח מהדפדפן, ולכן ניתן לזייף אותו. בגלל שרונית מאשרת כל הזמנה בוואטסאפ זה מספיק לשלב הזה, אבל כדאי לבדוק את הסכום לפני אישור.
- פרויקט Supabase חינמי נעצר אחרי כשבוע בלי פעילות. מחדשים בלחיצה ב-Dashboard.
- קטגוריות (סלטים, עיקריות, פטיסרי) מנוהלות בטבלת `categories`. להוספת קטגוריה: `insert into categories (id,title,sort) values ('x','שם',4);`
